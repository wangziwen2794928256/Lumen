# 需求覆盖与界面复查

本次从最初的 117 个编号章节、Phase 9.5 架构升级和后续简约/开源/英化等要求重新核对。章节覆盖矩阵在 [REQUIREMENTS_MATRIX](../data/REQUIREMENTS_MATRIX.md)。**主流程已实现，不等于所有原始细则全部完成；不宣称观赏性或手感达到绝对最佳。**

## 本次补齐与修复

- **每日运势**：侧栏「每日运势」，也可从 Today 右侧「看看今日签」进入。设置 → 高级 → 模块管理中可停用；隐藏只移除侧栏入口，不关闭首页卡片。
- 它是可选的可信 Official Module，使用 `lumen.fortune` manifest、Registry、ModuleGate 和 `today.sidebar` widget。没有新增数据库表、权限或网络请求。
- 日期采用设备本地公历日期；固定 12 条中英文签文按天轮换，同一天一致，午夜、恢复焦点和时钟变化后刷新。这是娱乐与灵感，不是预测，也不改变任务或容量。
- 模块设置保存/重新载入按钮增加 12px 间距及换行支持。
- 短窗口侧栏改为模块列表独立滚动，设置与组件入口留在底部可见区；保留折叠、拖动和键盘排序。
- 修复浏览器编程预览同步抛出 DESKTOP_REQUIRED 导致的未捕获异常，让现有错误文案正常显示。
- 移除页脚残留的 Phase 14，并更新诊断/关于页面仍称“业务功能未来开放”的过时说明。

## 明确仍有差距

| 优先级 | 发现 | 影响与后续方向 |
| --- | --- | --- |
| P1 | 原规格统一全局搜索未完成 | 现有通用 FTS 只覆盖任务/日记，其他模块是各自检索；没有完整统一入口与日期/类型/标签筛选。需独立增量设计和 migration，不应伪装已完成。 |
| P1 | macOS/Linux 未达桌面功能对等 | Today/Focus 会因会话事件 adapter 缺失而不可用；媒体、附件打开、deep link 等仍有限制。保留明确错误，不能为展示而取消计时保护。 |
| P2 | 原生英化不完整 | 前端双语；Rust 托盘、通知、部分诊断仍有中文。 |
| P2 | 原 Today 的歌曲卡片未接入 | 日记预览已有，音乐模块独立可用，但首页没有实际歌曲卡片与完整问候体验。 |
| P2 | 月度快照按访问生成 | 当前不是无人操作也自动月结的后台调度器；周回顾调整历史呈现、月快照照片画廊也有进一步空间。 |
| P2 | 大范围首次查询有延迟 | 本机隔离十年数据：首次 6217ms、缓存后 2694ms、七日 679ms。并行构建期间测得，非受控性能实验，不代表全部硬件。冷启动 ≤2.5s 未复验。 |
| P2 | 可移植导出是白名单 | JSON/CSV/Markdown 覆盖主要数据，但不是所有内部/偏好/权限表的完整替代；全量恢复应使用验证过的备份。 |
| P3 | Spotify / ActivityWatch 未完成 | 默认关闭，Spotify 仅接口，ActivityWatch 无实际集成。手工使用不依赖这些服务。 |
| P3 | 部分大型页面维护性不足 | InsightsPage 超过建议规模；后续渐进拆分，不在本轮批量改写稳定服务。 |

社区插件执行、完整 WASM Runtime、插件市场、AI Planner、移动端仍是**明确延后**，并非本阶段遗漏。Theme Packs/第三方生命周期主要为契约准备，不把源码级官方模块说成可直接安装的第三方插件。

## 验证范围与界面结论

前端 lint、format、typecheck、39 个 unit、build、81 项 Edge E2E 通过。后者包括既有业务回归、新每日签开关/持久化/隐藏区别/按钮间距，以及中文 14 路由 × 明暗 × 3 尺寸、英文同范围页面检查。尺寸为 1280×720、1440×900、1920×1080；有非零合成数据的既有业务工作流也重跑。

复查包含页面横向溢出、控件水平裁切、设置可达性、持久应用壳、键盘焦点、对话框与 reduced motion/对比度；截屏人工查看空状态与合成业务页。不是逐像素黄金图比较，也不是读屏软件实用户测评。没有使用生产记录生成截图。审美上保留低饱和、留白与清晰层级，新增模块不占用 Today 主任务列。

Rust 72 个测试通过，覆盖 migration、失败回滚、校验漂移、备份、恢复、权限和数据路径；十年性能用例另行显式执行通过。未改旧 migration，schema 保持 10。原生隔离窗口与正式 Windows 产物的最终验收回执记录在本机 Phase22 报告；本页不以浏览器 mock 替代原生计时验收。安装/升级/卸载保留数据和锁屏测试本轮不重复，仍引用旧版本历史证据，不能标成本轮通过。
