# 语言资源与英化包

默认 zh-CN，新增 en。资源在 `src/locales/en/messages.json`，查找/持久化在 `src/lib/locale.ts`，选择控件在 `src/features/appearance/LanguagePanel.tsx`。现有静态中文文案作为稳定 source key，translate 返回当前语言显示文本。它只对开发者写入的界面字面量调用，不对数据库正文调用。导航直接选择 Manifest.name[locale]。

## 使用

设置 → 外观 → 界面语言。先保存当前编辑，选择 English 后点击应用，界面重新载入。localStorage 键 lumen.locale.v1 保存 en/zh-CN，未知值或读取失败回落中文，保存失败给出提示。不会修改 core SQLite/schema 或用户文本。重载是明确按钮操作，避免挂载中途更改一半文案；请勿在未保存工作时应用。

## 翻译贡献

新增静态文案调用 translate('中文原文')，并在英语 JSON 添加同名键和值。键仅代表界面语义，不能传入 user.title 或 entry.body。字符串改变需同步资源，避免英语悄悄回落中文。多段句子优先重组完整模板，未来插值/复数格式可再演进，不用拼接来推断语法。新增 locale 要扩 Locale 类型、加载表、选择器和 Manifest name/schema，再补日期格式及测试。

## 验收

unit 覆盖默认/非法值、持久化、英文查找和未知用户内容保留；E2E 覆盖双向切换/重启持久化、13 路由 × 双主题 × 三窗口、无中文界面残留（语言自称除外）与无水平溢出。测试使用浏览器空状态，不代表所有原生 IPC 错误或 OS 对话框已经英化。

## 范围

本包包含 905 条既有前端独立静态文本，另有语言控件自身双语文案；用户记录、附件名、考试资料和自建目标保留原文。OS 文件选择器跟随系统；当前 Rust 托盘/通知和部分后端诊断正文仍为中文，后续应以稳定错误码和原生 locale 服务统一，不能声称全系统语言完全一致。此限制不影响前端英语操作路径。
