# 备份、恢复与隐私

Phase13 的备份、恢复、导入与隐私操作由 Kernel 执行，入口为设置中的“本地备份”和“隐私中心”。所有操作本地完成；私有导出与公开网站投影分开，不增加上传或 AI 调用。

## 完整备份与保留

应用启动及运行期间每5分钟检查，默认启用，按本地日期及 ISO 周保留最近7日、4周、6月分桶的最新快照；各层取并集，不复制17份。错过的日期不补造快照。可配置范围1–90日、1–52周、1–60月。修改策略不会中断已开始的操作；当天已有有效快照时不重复创建或清理，保留新策略在下一份新的每日快照成功后生效。未安装 Windows 服务或系统计划任务。

完整备份包含 SQLite 一致性快照（包括设置）、程序/schema版本、SHA256 manifest，以及包括回收站在内的附件实体。COMPLETE 保存 manifest 哈希，只有数据库完整性、外键、migration校验、可读样本和附件大小/hash全部通过后才写入。失败目录不返回成功；存储不足等 I/O 错误会中断操作，未成功创建新快照不得触发保留清理。未进行真实耗尽物理磁盘实验。

保留只处理备份根目录直接子项中名称正确、路径安全且验证成功的 daily-DATE-UUID。手动、迁移、未来日期、损坏、未完成、异常命名及链接越界目录均保护。手动备份不自动清理；旧迁移备份保留原验证兼容性，没有完整附件和COMPLETE的旧备份不能作为本页完整恢复源。

## 便携数据交换

JSON 格式 lumen-data-backup/1、schema10，固定24张表白名单，包括日记、专注、任务、音乐、编程、作品六类正文与关联业务实体。不含附件实体/附件关系、设置、偏好、集成授权、凭据及派生/只追加分析数据，不能替代完整备份。CSV/Markdown各输出六类文件，记录为结构化JSON，可脱离SQLite阅读。导出COMPLETE仅表示写入完成，不是密码学签名。文件为本地明文，位于exports/private-UUID。

通过原生文件选择器选择JSON；上限64MiB、10万条记录、每字符串100万字节。在事务中验证版本、列、原始类型、UUID、URL、约束和外键，再完整回滚，显示新增/更新/冲突/无效/未变化数量。冲突或无效会阻止整批写入。现有不同记录只有incoming updated_at更新才允许更新，不自动合并；须先结束本地专注，来源中的未结束专注也会拒绝。

审阅时的文件内容冻结在内存；确认导入该快照，不重新读取后来修改的磁盘文件。一次性token和来源/当前数据指纹保护确认，本地业务数据变化需重新审阅。确认先创建完整备份，再在单一事务中写入；失败不提交。相同ID不会重复新增，revision变化可能让不同内容的重复导入需要重新处理冲突。专注统计按interval重建，导入不会开启任何集成。

## 隔离恢复与可审查候选

选择含COMPLETE的完整备份文件夹。Kernel先校验来源，再复制至cache/restore-UUID，通过真实Database启动路径打开，验证schema、完整性及可读样本，关闭后重新封装DB哈希并再次完整验证。RESTORE_REVIEW.json只记录汇总。产出候选可供后续离线恢复审查，本阶段不覆盖或切换当前数据库；AGENTS.md明确禁止覆盖生产数据库。恢复决定完成前保留来源和候选。

## 隐私与边界

窗口标题、浏览器URL、文档名和私人文本追踪未实现且不采集。Windows媒体监听新安装默认关闭，已有用户明确偏好保留。隐私中心只显示有效集成/凭据引用数量，不暴露secret。断开操作事务内关闭监听、清除来源和凭据引用、软删除集成账户；显式删除只将windows-media播放移入回收站，手动历史保留。远端服务token撤销仍需到服务账户操作，未新增凭据服务接入。

打开数据目录由Kernel平台服务解析实际根路径，Windows实现；macOS/Linux原生打开目录和打包未验收。备份没有加密或数字签名。物理磁盘耗尽、断电及真实外部服务撤销NOT RUN。受computer-use指导限制，原生界面更改隐私设置与删除NOT RUN，隔离Rust与E2E覆盖其行为。
