# CONTRIBUTING

项目采用MIT；贡献者须有权提交源码并保留第三方许可证，不上传私人SQLite、正文、密钥或生产截图。默认zh-CN，技术文档中英对应；模块API变更同步契约与测试。

分支开发，读代码后小范围修改；禁止重写稳定domain或修改已发布migration。schema只能新增编号，迁移/rollback/备份与生产保留测试必须通过。Kernel权限降级不能只靠renderer。

PR写问题、结果、兼容/数据影响与实际测试；NOT RUN不能标PASS。新的官方模块先经注册表与Widget试点，社区功能没有执行豁免。公开仓库/发行仍需另行用户发布指令。

本文件对应英文版本：[CONTRIBUTING](../en/CONTRIBUTING.md)。
