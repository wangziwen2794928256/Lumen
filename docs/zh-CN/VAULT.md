# 作品库与作品集

Vault 属于 Official Module，支持十种作品类别及带版本检查的录入、编辑、归档、回收和恢复。默认私密。010 增量迁移保留旧表、旧行与原迁移校验值，增加日期、角色、组织、技能、技术、链接、关联和版本字段。

点击新建作品，填写自己的真实文本并保存，然后导入20 MB以内PDF、PNG、JPEG或WebP。原生选择器将文件复制到受控附件目录，保留文件名、大小、MIME与SHA-256。校验可识别缺失、改变的文件；打开操作拒绝这两种情况。归档和回收不会删除附件，恢复回到当前作品。

作品集预览仅显示明确标记公开、未归档、未删除的作品和用户原文。附件及关联实体的私密标题不会进入预览。公开标记仅影响本地预览，不上传、不发布。列表最多显示最近1000项；旧类别直到用户主动保存编辑时才转换。详细边界见[数据契约](../data/VAULT.md)与[技术手册](TECHNICAL_HANDBOOK.md)。原 Phase11 原生验收报告含私人截图，保留本地。
