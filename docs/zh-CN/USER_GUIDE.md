# 使用指南：从一天到一段成长过程

## 第一次打开

安装 Windows 候选后首次引导可以填写主要目标、科目和工作/周末分钟，也可跳过。引导不会开启音乐、Spotify 或活动追踪。模板和示例不是你的成绩或历史。先在设置确认备份策略与数据目录。要英文界面，在外观选择 English，保存编辑后应用并重载。

## 用最小流程开始

1. 在 Roadmap 建立自己的 Journey，例如“十二周专业基础巩固”。用学科或阶段组织内容，容量按真实可用时间填写。
2. 在 Today 建一个当天任务，填写估时。开始专注后需要休息就暂停；锁屏停止累计，回来后手动继续。
3. 完成并结束会话，留下真实时长；未完成时不要为了统计把任务标完成。
4. 用随手记或 Quick Capture 写下当天的问题与思路。正式日记支持 Markdown、标签与关联。
5. 在 Insights 看计划与实际，写自己的心得。特殊日可以标记休息/生病，不抹掉已有成果。

## 不同成长场景

| 场景 | 起步方式 | 建议保留的事实 |
| --- | --- | --- |
| 考研 | 数学/英语/专业课学科，分阶段复习 | 每次真实练习、错题原因、估时差异 |
| 考公 | 行测专题与申论练习，固定模考日程 | 专题用时、复盘笔记、实际完成情况 |
| 语言学习 | 阅读、听力、口语任务及学习日记 | 练习材料、理解问题、手工时长 |
| 科研 | 论文/实验 Journey、截止日期、实验日志 | 推导、来源、失败尝试、成果链接 |
| 职业与作品 | 技能树、面试题、项目里程碑 | 代码尝试、证书、实际作品与个人贡献 |

目标与模板都可修改。规划建议只参考你输入的容量与约束，不评判努力、不预测考试结果。

## 管理模块和布局

设置的高级分组可以停用、隐藏、置顶与排序。隐藏只影响侧栏，停用阻止模块页面但不删除数据。置顶组先显示，组内可拖动或用上下按钮。颜色与主题统一在外观分组，模块不各自复制一份强调色设置。Kernel 安全始终有效，今日核心不可停用。

## 记录与公开是两条路径

Vault 默认私密；主动设公开的作品可进入 Profile 白名单投影。先保存档案、检查投影，再手工导出网站。本地预览不等于发布。日记、原始专注、音乐历史、附件和私有关联不会进入网站。私有 JSON/CSV/Markdown 可能含私人内容，只交给你信任的位置。

## 保护记录

完整备份包含数据库、设置和附件。便携 JSON 是数据交换，不是全量附件备份。恢复演练在隔离目录进行，不覆盖当前库。遇到校验或磁盘错误先保留原件，不删除 DB/WAL，也不重新初始化来“修复”。删除通常进入回收站，可以恢复。

## 当前限制

Windows 为主验收平台。macOS/Linux 实验原生包的 Today/Focus 当前不可用，媒体监听及部分打开助手不支持。社区插件执行、完整插件市场、AI 调用、移动端、ICS 导入均未实现。英文包覆盖现有前端文案，原生 OS 对话框由系统语言决定，Rust 托盘/通知仍有中文文案。

## 每日运势在哪里

侧栏「每日运势」或 Today 右侧「看看今日签」。设置→高级→模块管理可以关闭。固定签文随本地日期轮换，仅供娱乐；不采集生日，不联网，不影响计划。
