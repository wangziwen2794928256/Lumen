# 桌面体验

Kernel `src-tauri/src/kernel/desktop.rs` 统一管理托盘、重复启动、窗口恢复、自启动和通知。固定版本的官方 Tauri 插件接入，不新增社区 native 执行或宽泛 JS 权限。单实例插件最先注册；只恢复主窗口尺寸、位置与最大化，不恢复隐藏/最小化，不恢复快速记录窗口。

托盘六项：打开、开始专注、快速记录、暂停专注、今日、退出。复用 TodayService 和快速记录服务，不建立另一套计时器或数据库写入逻辑。无会话时选取今日首个 active/planned 任务开始；已有会话则打开；无任务时打开专注页供手动操作。重复启动仅接受现有 lumen:// 严格路由白名单并激活主窗口。

自启动默认关闭，只有通用设置中的明确操作才注册，并读取真实系统状态；失败显示可恢复提示。默认关闭窗口正常退出；留在托盘必须手动开启且托盘已成功建立。退出操作保存窗口状态后结束应用。

通知总开关默认关闭，四类为专注结束、五分钟内固定日程、上周日记回顾、备份失败。正文不包含任务标题、日程标题或私人正文。启动不请求权限；接口 Granted 不保证系统展示。运行期间每30秒检查，日程去重记录六分钟过期，会话完成使用时间戳与 ID 游标，每 ISO 周仅一次回顾，备份错误变化时提示。通知为尽力发送，重启不补发历史通知。

引导最多五步：主要目标、容量、科目、可选快捷键、确认。可跳过且不创建个人记录；完成时复用路线图校验和事务，仅创建明确输入的内容，科目去重，重试幂等。已有业务记录不会出现引导，事务内再次校验防止并发覆盖。快捷键冲突保留已保存手动数据并允许进入；不会开启任何集成或追踪。

设置页十三个可键盘定位的分组复用现有外观、规划、快捷键、模块、备份和隐私面板。文案集中维护，表单和动作保留间距，验证三尺寸和明暗主题。数据使用现有 settings 表 desktop.v1 / onboarding.v1，桌面设置带 revision 冲突保护；不修改 migration。

验证命令 scripts/verify/phase14.ps1；隔离 Rust、浏览器 IPC fixture 和原生证据见 docs/testing/phase14。浏览器 fixture 不代表真实系统自启动/通知投递通过；macOS/Linux 原生构建和投递未宣称通过。
