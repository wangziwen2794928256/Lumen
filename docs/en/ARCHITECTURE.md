# ARCHITECTURE

Four layers: Kernel, bundled Official Modules, future isolated Community Modules, and token-only Theme Packs. The Kernel owns security, core storage, migrations/backups, registry, platform adapters, permission enforcement and plan exchange. Security cannot be uninstalled.

Previously React hardcoded navigation and routes called Tauri domain commands; Today/Journal contained OS branches. The new boundaries wrap stable services without rewriting them. Insights is the first migrated official module; other features retain legacy bridges or planned placeholders. Everything is a Module means composable responsibilities, not removable security.

Local-first, Open Source (MIT), Privacy by Architecture, Manual First / AI Optional, Cross-platform and Reproducible by Design guide future work. No account, cloud or public publication is required.
