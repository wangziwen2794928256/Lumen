# MODULE_SYSTEM

Bundled manifests contain id, bilingual name, SemVer version, API 1.0, layer, route, icon, required, status and permissions. IDs/routes are unique. The compiled trusted catalogue cannot be replaced by user-supplied official/kernel claims.

Registry preferences persist enabled/hidden/pinned/order. Hidden affects navigation only; pinned groups precede other modules with stable ordering. Settings supports drag and keyboard move buttons with explicit save; sidebar drag saves directly. Revision conflicts refuse overwrite. Required Today and Kernel settings/security remain available. Disabling never deletes domain data.

Insights gates its route, widget, IPC and background month worker. Legacy modules have compatible UI gates while Kernel focus safety continues; this is gradual migration, not complete domain isolation. Widgets use today.after-summary and a per-widget error boundary.
