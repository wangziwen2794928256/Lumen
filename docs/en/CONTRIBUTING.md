# CONTRIBUTING

Lumen is MIT-licensed. Contributors must own submission rights and preserve third-party notices. Never upload private SQLite, bodies, secrets or production screenshots. Default UI remains zh-CN; technical documents have matching English versions.

Use feature branches and small changes after reading stable domains. Released migrations are immutable; schema changes need new numbered migrations and rollback/backup/preservation tests. Renderer checks alone cannot enforce Kernel authority.

PRs explain the problem, resulting behavior, compatibility/data impact and actual validation. NOT RUN is not PASS. Official modules are migrated gradually; community code receives no execution exemption. Public publication still requires user instruction.
