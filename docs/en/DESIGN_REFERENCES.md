# Presentation and documentation references

Research date: 2026-10-11. These references inform structure and design, without copying brands, marks, pages or wording or implying endorsement.

- [Apple WWDC25 Platforms State of the Union](https://developer.apple.com/videos/play/wwdc2025/102/): a platform overview followed by concrete technologies and developer opportunities. Lumen follows a sequence of growth contexts, product workflow, module architecture, contribution paths and verified boundaries.
- [VS Code Extension API](https://code.visualstudio.com/api/) and [Extension Anatomy](https://code.visualstudio.com/api/get-started/extension-anatomy): separate concepts, a starter example, contribution points and reference. Lumen separates user guidance, a hands-on tutorial, API index and security contracts. VS Code APIs are not presented as Lumen APIs.
- [Tauri prerequisites](https://v2.tauri.app/start/prerequisites/): official native requirements inform configuration guidance and the distinction between using a package and developing from source.

## Visual direction

Lumen keeps warm white, deep forest and sage. Large typography, one subject per slide, generous space and real synthetic UI support the product story. Dark chapter slides establish rhythm, product screenshots lead feature pages and a few editable tables/code excerpts explain technical boundaries. Chinese and English have separate decks. Markdown contains implementation detail, while slides retain speaker notes and explicit current/future status.

Native editable text, tables and notes support adaptation. Screenshots show isolated synthetic states without private records. No invented adoption, performance gains, examination results or platform support. Reproducibility does not promise bit-identical binaries across machines. Signing and real-device limitations remain visible.
