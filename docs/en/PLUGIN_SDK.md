# PLUGIN_SDK

This phase supplies a CommunityManifest model, deny-by-default policy, lifecycle state machine and draft WIT only. There is no installer, marketplace or executable SDK. Community manifests allow a fixed plugin.wasm component entry, never native code.

Future component ABI 1.0 imports storage key/value access in its own namespace, declarative widget contributions and plan proposals. No raw HTML/scripts, Tauri invoke, core database path or host file handle is exposed.

Plugin API versions are independent of app versions. Only 1.0 is currently accepted; unsupported major/minor versions fail closed. Future additive minor negotiation must be explicit; old adapters remain during a documented deprecation period. Schema changes require paired TypeScript/Rust fixtures.
