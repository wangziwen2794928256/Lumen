# Vault and Portfolio

Vault is an Official Module with ten artifact categories and revision-protected CRUD. Records default to private. Migration 010 preserves legacy tables and rows, adds date/role/organization/tags/URLs/references/revision, and records idempotent requests.

Use New Artifact, enter your own text, save, then import PDF/PNG/JPEG/WebP up to 20 MB. The native picker copies files to controlled attachments with size/MIME/SHA-256. Verify reports missing or changed content; Open refuses either. Archive and Trash retain attachments; Restore returns the record to active state. Legacy categories are preserved until explicitly edited.

Portfolio Preview includes only public, live, unarchived records and the user's existing text. Files and linked private entity titles are excluded. The public flag is a local preview selection; nothing is uploaded or published. Lists are bounded to the most recent 1000 records. See [data contract](../data/VAULT.md) and [phase report](../reports/PHASE_11_REPORT.md) for limits and evidence.
